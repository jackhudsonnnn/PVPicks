# P2Picks

P2Picks contains a browser-local frontend prototype and a development-only
Spring Boot backend. The backend is not ready for real users or LAN deployment.

- [Developer handbook and roadmap](docs/site/index.md)
- [Documentation source map](docs/README.md)
- [Backend setup](backend/README.md)
- [Frontend prototype](client/README.md)

After installing the documentation dependencies and starting the dev backend,
the handbook is available locally at `/docs/`. Preserve existing databases
and credentials; do not run destructive reset commands without approval.
