# P2Picks

P2Picks is a peer-to-peer betting app for friend groups: a React frontend and
a development-only Spring Boot backend. It is not ready for real users or LAN
deployment.

- [Developer handbook and roadmap](docs/site/index.md)
- [Documentation source map](docs/README.md)
- [Backend setup](backend/README.md)
- [Frontend](client/README.md)

After installing the documentation dependencies and starting the dev backend,
the handbook is available locally at `/docs/`. The project is pre-MVP: the
local dev data is disposable and may be reset. Never commit credentials.
